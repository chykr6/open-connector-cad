# 通用端子生成器实施计划

## 目标

用一个命令行生成器创建不同系列、间距、极数和逐极压杆配色的端子模型，避免复制 1P、2P、4P、8P 专用脚本。

## 架构

- `profiles/<series>-<pitch>.json` 只保存该间距图纸对应的真实尺寸和默认颜色。
- `connector_generator.py` 负责参数校验、装配几何、FCStd/STEP 输出和模型元数据。
- `generate_connector.ps1` 提供 Windows 命令入口，并用 FreeCAD GUI 模式保存显示颜色。
- `connector_verify.py` 根据模型内参数动态验证任意极数，而不是写死 3P。

## 全局约束

- DA803-350、DA803-500、DA803-750 使用独立尺寸 profile，禁止按比例缩放替代图纸尺寸。
- 输出名称使用 `<series>-<pitch-code>-<poles>P[-<variant>]`。
- 主体、侧盖、压杆和金属焊脚颜色分开配置。
- 压杆颜色允许一个颜色应用全部极，或提供与极数相同的逐极颜色列表。
- 未经用户明确要求，不执行 Git 暂存或提交。

## 任务

1. 先测试间距编码、颜色规范化、颜色列表展开、variant 文件名和错误输入。
2. 创建 `DA803-350.json`，迁移当前 3.5 mm 图纸尺寸。
3. 重构现有几何函数，使其只依赖 profile 和生成请求。
4. 生成任意极数的模块、侧盖、压杆和双排焊脚。
5. 在 FCStd 中记录系列、间距、极数、variant 和全部颜色。
6. 使用 GUI 模式保存部件显示颜色，并尝试以带颜色的 STEP 模式导出。
7. 动态验证总宽、模块数量、侧盖宽度、焊脚数量、颜色元数据和 STEP 实体数。
8. 生成 `DA803-350-3P-black-blue-green` 作为当前实际配色模型。
9. 验证 1P、2P、4P、8P 请求使用同一生成器且无需新增 Python 文件。
10. 侧面几何验证压杆前端伸出、压杆直线斜边、主体手掰斜坡和封闭背面。
